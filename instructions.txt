How to run the symon-mockserver:

1. podman load -i symon-server.tar
2. podman compose up -d

Interfaces:
1. In the routes.interface.ts you will find all the REAST API of the server.
2. In the socker-events.interface.ts you will find all the WS endpoints between the server to the client.
3. All the other files is the interfaces that the servr use to communicate with the client.

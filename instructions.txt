How to run the symon-mockserver:

Via podman:
1. podman load -i symon-mock-server.tar
2. docker-compose up -d


Via Docker:
1. docker load -i symon-mock-server.tar
docker-compose up -d

Interfaces:
1. In the routes.interface.ts you will find all the REST API of the server.
2. In the socker-events.interface.ts you will find all the WS endpoints between the server to the client.
3. All the other files is the interfaces that the server use to communicate with the client.
